Support

Play in a current standalone browser over HTTPS. The microphone is optional; Space, Arrow Up, and tapping the playfield use the same jump-and-lift controls.

Target browsers

  • Safari on current iOS devices
  • Chrome on current Android devices
  • Current desktop Chrome, Edge, Firefox, and Safari

Embedded social-media browsers are not supported. Older operating systems, legacy browser releases, and unusual audio devices may work but are not part of the MVP support target.

Install and offline play

In supported Safari or Chrome browser menus, choose Add to Home Screen or Install app after the first online load finishes. A previously loaded release can then reopen and play locally without a network connection. Microphone and camera availability while offline still depends on the browser and installed-app secure context; keyboard and touch remain available.

Releases never replace the running game automatically. If an update finishes downloading during a run, the game waits until the run ends, shows Game update ready, and reloads only after you choose Update now.

Microphone troubleshooting

  • Open the game directly in Safari or Chrome rather than an embedded browser.
  • Allow microphone permission when the browser prompts.
  • Check that the microphone icon and live activity meter respond before capturing.
  • Use a comfortable voice and retry only the highlighted step in a quieter room. Never shout.
  • If calibration playback is unavailable, continue with the live meter; playback is not required for calibration.
  • If audio was interrupted, return to the tab and select the resume action.
  • Choose keyboard or touch fallback if the microphone is unavailable.

Camera troubleshooting

The front camera is optional and independent of microphone play. If permission is denied or the camera stops, the original game background remains active. Turn the camera off and retry from the game control.

Known MVP limitations

  • Derived calibration, settings, and completed-run bests are local to this browser and do not sync to another device.
  • The first load and every new release need a network connection before that release is available offline.
  • There are no accounts, online leaderboards, cloud replays, or remote analytics.
  • Landscape phone play pauses until the device returns to portrait.

Settings and local data

Open Accessibility & settings to choose keyboard/touch or voice, adjust a saved voice threshold, recalibrate, mute, reduce motion, disable screen shake, remember camera preference, or reset game-owned data. Camera still requires its own explicit enable gesture. Corrupt or unsupported saved data safely restores defaults.
