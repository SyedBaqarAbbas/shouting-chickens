# Original app icon

`app-icon.svg` is original Shouting Chickens artwork created for this repository. It does not copy
the people, watermark, logo, or game art in the product-reference screenshots.

The committed PNG install icons are reproducibly generated from the same original geometric design:

```bash
npm run generate:icons
```

The source and generated icons are covered by this repository's license. Keep the 20% safe area
around the chicken and voice rings when changing the maskable icon.
